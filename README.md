# QuickNotes

QuickNotes is a simple note-taking web application built using HTML, CSS and JavaScript. It allows users to create, organise, search and delete notes in different categories. Notes are saved in the browser using localStorage, so they remain available after refreshing the page.

## Features

* Add notes under Personal, Work and Study categories.
* Validate empty notes and notes exceeding 200 characters.
* Search notes without case sensitivity.
* Delete individual notes.
* Display the number of saved notes.
* Show the date and time each note was created.
* Save notes in browser localStorage.
* Responsive layout for desktop and mobile screens.

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Start adding, searching and deleting notes.

No additional packages are required.
